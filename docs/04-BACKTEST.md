# 백테스트 — 감시 트리거 규칙에 우위가 있는가 (2020-01 ~ 2026-09)

작성 2026-09-26. 도구: `server/backtest/run.js` (Claude 호출 0 · 네트워크 0 · 실행 2초).
데이터: BTCUSDT·ETHUSDT 바이낸스 USDⓈ-M 15분봉 각 236,167개 + 일봉 (1차 프로젝트가 받아둔 `reports/backtest/data/`).

## 한 줄 결론

**감시기가 "분석할 자리"로 고르는 트리거 자체에는 우위가 거의 없다.** 기계적으로 방향을 정해 6.7년을 돌리면 BTC 는 PF 1.05(비용 빼면 동전던지기), ETH 는 마이너스다. 채택 기준(PF ≥ 1.3 · 계좌DD ≤ 15%)을 통과한 조합은 **없다.** 유일한 포켓은 "BTC 급락 후 20일 저점권 매수"인데 표본이 104건이라 가설 이상은 아니다.

즉, 실전 수익은 **AI 판정 층이 이 동전던지기 후보 집합에서 우위를 만들어내야** 생긴다. 그게 되는지는 데모 실적(Phase 1)으로만 알 수 있다.

## 방법

| 재현한 것 (실제 코드 규칙) | 대체한 것 |
|---|---|
| 트리거: 15분 전 대비 \|변동\| ≥ 1.5% (`watcher._evaluate`) | AI 12명의 방향 판정 → 기계 규칙 5종 |
| 추세 필터: 가격 vs SMA20 · MACD 히스토그램 방향 일치 (`structureAgreesWithDirection`) | 진입/손절/목표 레벨 → ATR 기반 고정 규칙 |
| 역추세 필터: 20일 구간 하단/상단 20% (`reversalAgreesWithDirection`) | |
| 쿨다운 60분 · 포지션 1개 (exchange 의 기존 포지션 차단) | |

전략 5종: `trend`(추세 동의 시 움직인 방향) · `reversal`(역추세 동의 시 반대 방향) · `any-trend`(둘 중 하나 통과 시 움직인 방향 = 실전 후보 집합) · `raw`(필터 없이 움직인 방향) · `raw-rev`(필터 없이 반대).
출구: 손절 = ATR(14, 15분봉) × 1.5 · 목표 = 손절거리 × 1.8 · 최대 보유 48봉(12시간). 같은 봉에서 손절·목표 동시 도달이면 손절. 진입 = 다음 봉 시가.
비용: 테이커 0.05% + 슬리피지 0.02%, 양쪽 → 왕복 0.14%. 펀딩비 미반영.
계좌DD = 명목 DD × 20% (실전 `execution.maxPositionPct`).

## 해석

1. **후보 집합은 동전던지기다.** 필터를 다 걸어도(`any-trend`) 필터 없는 `raw` 와 PF 가 같다(1.05 vs 1.05). 필터가 거르는 건 트리거 수이지 질이 아니다.
2. **`any-trend` = `trend` 수치가 완전히 같다.** 20일 저점권(역추세 조건)에 있으면 거의 항상 SMA20 아래(추세 조건)라, 역추세 필터는 후보 게이트로는 아무것도 더하지 않는다. 의미가 있는 건 **방향을 뒤집을 때**뿐이다.
3. **ETH 는 어떤 규칙으로도 음수.** 변동성이 커서 1.5 ATR 손절이 자주 걸린다(ETH 는 손절 2 ATR 이웃에서만 양수).
4. **숏은 근거가 없다.** 모든 전략에서 숏 쪽 기대값이 0 이하다.
5. **표본이 작다.** H1 표본외 18건은 통계가 아니다. 좋아 보이는 숫자일수록 의심한다.

## 결정 (대표이사)

- **D1.** 감시 트리거만으로는 실전 진입 근거가 되지 않는다. 실전(Phase 2) 진입 조건에 "데모 30건" 외에 **"AI 판정 집합이 같은 기간 기계 규칙(H1·H2)보다 낫다"** 를 추가한다. AI 가 동전던지기 위에서 우위를 못 만들면 AI 를 쓸 이유가 없다.
- **D2.** H1·H2 를 **가설로 등록**하고 데모 기간 동안 전방 검증한다(구현: 감시기가 트리거마다 H1/H2 의 기계 판정을 후보 로그에 함께 기록 → 4주 뒤 AI 판정과 나란히 성적 비교).
- **D3.** 실전(Phase 2)에서는 **숏 금지**를 기본값으로 검토한다. 데모에서는 허용해 데이터를 모은다.
- **D4.** 오너가 보낼 영상의 전략은 전부 이 틀(`engine.decideSide` 에 전략 추가)에 태워 같은 표로 비교한다. 영상 속 "월 30%" 는 이 표에서 PF 1.3 을 넘기 전까지 0 의 가치다.
- **D5.** 설정은 바꾸지 않는다. 트리거 2% 가 더 좋아 보이지만 AI 후보 데이터가 줄어든다 — 데모 표본이 먼저다.
