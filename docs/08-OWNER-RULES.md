# 대표님 매매 규칙 한 장 (2026-10-23)

근거는 `docs/07-RESEARCH-PROTOCOL.md` '오너 직접 매매 규칙' — BTC·ETH 2020-07 ~ 2026-09, 수수료·펀딩 포함 시험. 겨루기 규칙(`docs/00-CEO-PLAN.md`)과 함께 지킨다.

## 기본
- **종목:** BTC·ETH + 바이낸스 상장 미국 주식. 주식은 롱만(주식 칸은 서버 확인 전).
- **레버리지 1배.** 바이낸스는 종목마다 따로 설정 — 처음에 하나씩 확인.
- **한 칸 = 순자산의 20%, 한 번에 최대 3종목(= 60%)** — 대표님 결정(2026-10-23). 들어갈 때마다 그날 순자산으로 다시 계산. 한 종목에 한 칸. 3칸이 차 있으면 새 신호는 건너뛴다(먼저 든 것을 빼고 바꾸지 않는다). 다섯 종목을 다 20% 로 들면 계좌 최대 손실 −26% 였다.
- **차트:** 트레이딩뷰 **일봉 SMA 50 · SMA 200** 두 개만. 4시간봉은 안 본다. 주식은 실제 주식 차트(`NASDAQ:NVDA` 등).
- **시각:** 매일 **17:30**, **오늘 아침 9시에 마감된 일봉 종가**로만 판단.
- **매일 09:05 텔레그램 신호**(`server/owner-signal.js`): 종목마다 마감된 종가 · 50일선 · 200일선 숫자와 거리 %, 그리고 할 일(유지·진입·정리). 17:30 에 이대로 한다. 언제든 **/신호** 로 다시 받는다.
- **'위·아래'는 숫자로만:** 마감된 봉의 종가와 그 봉의 SMA 값을 비교 — 1원이라도 낮으면 아래. 여유 폭을 두면 덜 벌고 더 잃었다. 아직 안 끝난 오늘 봉은 보지 않는다.

## 매일 17:30 (5분)
1. **들고 있는 것:** 롱은 종가가 선 하나라도 **아래**, 숏은 선 하나라도 **위**로 마감했으면 → 지금 정리. 지금 가격이 다시 선 안이어도 정리.
2. **빈 칸:** 아래 조건에 맞으면 → 지금 진입. 지금 가격과 상관없이.
3. **들어가면 5분 안에** 손절·익절 주문을 건다. 주문 없이는 절대 들어가지 않는다.
4. 끝. 21:00 까지 다시 판단하지 않는다.

| | 롱 | 숏 (코인만) |
|---|---|---|
| 들어가는 조건 | 종가가 두 선 **모두 위** | 종가가 두 선 **모두 아래** + **50일선이 200일선 아래** + **200일선이 20일 전보다 낮음**(내려가는 중) |
| 손절 | 진입가 **−10%** | 진입가 **+4%** |
| 익절 | 진입가 **+30%** | **없음** — 아래 '정리'로만 나온다 |
| 정리 | 종가가 선 하나라도 아래 | 종가가 선 하나라도 위, 또는 50일선이 200일선 위로 |
| 들고 있는 동안 | 두 선 위면 유지 | 두 선 아래 + 하락 배열이면 유지(200일선 기울기는 들어갈 때만 본다) |

- **숏 규칙은 2026-10-23 다시 정했다.** 처음 정한 손절 4%·익절 8% 는 17:30 에 들어갈 때만 플러스인 '시각 운'이었다(09:00 연 −4.7%). 새 규칙은 들어가는 시각 4개(09·13·17:30·21시)와 두 기간(2020~23·2024~) 모두 플러스였다. 숏 칸 혼자는 1년 3~5% 로 약하지만, 롱이 쉬는 하락장에서 벌어 계좌 전체를 2~3%p 올린다. 신호에서 숏을 빼려면 `node ops/owner-signal.js --no-short`.
- **익절된 뒤:** 다음 날 아침 종가도 조건에 맞으면 다시 진입(새 손절·익절).
- **장중에 선이 뚫려도** 그냥 둔다 — 걸어 둔 손절이 지킨다.
- **폰을 못 보는 날:** 걸어 둔 주문이 지킨다. 다음에 보는 날 그날 아침 종가로 1~3 을 한다. 따라잡으려 서두르지 않는다.
- **입금:** 다음 진입부터 반영. 들고 있는 포지션에 더 넣지 않는다.
