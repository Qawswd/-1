# 월 3% 탐색 — 사전 등록 프로토콜 (2026-10-15)

오너 요청: "모든 방법을 총동원해서 월 3%씩 안전하게 버는 걸 찾아와." 시험 **전에** 기준을 적어 둔다 — 결과를 보고 기준을 바꾸지 않는다.

## 목표의 숫자 정의
- 월 3% = 연 42.6%(복리). "안전" = 전체 돈 기준 최대 손실 ≤ 20%.
- 즉 어떤 비중에서든 **연수익 ÷ 최대 손실(칼마) ≥ 2.1** 이 필요하다. 지금까지 가장 좋은 것(추세추종): 전체 기간 0.8, 2024년 이후 섞기 최대 1.7.

## 데이터·기간
- BTC·ETH 바이낸스 선물 15분봉·일봉·펀딩비 2020-01 ~ 2026-09 (로컬). 다른 코인은 서버에서 받는다.
- **규칙 만들기·설정 고르기: 2020~2023.** **시험: 2024-01 ~ 2026-09** — 시험 구간 결과로 설정을 다시 고르지 않는다.

## 통과 기준 (전부)
1. 시험 구간(2024~) 칼마 ≥ 2.1 그리고 연수익 > 0
2. 규칙 만들기 구간(2020~2023)에서도 칼마 ≥ 1 (한 구간에서만 좋은 건 우연)
3. 설정 이웃(주요 값 ±1~2단계)의 70% 이상이 같은 방향(플러스) — 한 점만 좋은 건 우연
4. BTC·ETH 둘 다에서 플러스(한 종목만 되는 건 우연 가능성)
5. 비용: 한쪽 0.07%(테이커 0.05 + 슬리피지 0.02), 실제 펀딩 반영. 레버리지 1배 이하

## 시험할 가족 (미리 적어 둔 목록 — 여기에 없는 걸 나중에 끼워 넣으면 그 사실을 기록한다)
- A 추세추종 + 변동성 맞춤(위험 같게 나누기)
- B 추세추종 + 쉬는 동안 펀딩비 차익
- C BTC/ETH 비율 되돌림(짝 매매)
- D 펀딩비 극단값 역발상
- E 요일·시간대 계절성
- F 장중 돌파 + 일봉 추세 필터
- G 여러 코인 순환(상대 강도) — 서버 데이터
- H 위 생존자들의 조합

## 기록
시도한 변형 수를 전부 센다. 많이 시험할수록 우연히 좋아 보이는 게 나올 확률이 커지므로, 보고할 때 "몇 개 중 몇 개 통과"로 말한다.
