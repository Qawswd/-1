## 근본 원인 4가지

### 1. 연료 — Claude 사용량 한도 (가장 큼)
- 알고리즘 모드 1회 = 에이전트 12~13명 × `opus`. 실패하면 각 에이전트가 **한 번 더 재시도** → 헛돈 호출 2배.
- 워치리스트가 미국주식 10종이라 트리거가 자주 왔고, 한도가 차면 **그 뒤 모든 런이 12명 전원 실패**로 기록됐다. 3일간 실패 런 160회 = 헛돈 호출 약 3,800번.
- 한도 메시지 `You've hit your session limit · resets 6:40pm (UTC)` 를 진단이 "JSON 형식 오류"로 오진해(674건) 09-22까지 한도 게이트가 작동하지 않았다.
- 09-22 이후에도 실패가 이어진 이유: 한도가 풀리자마자 opus 12명이 다시 5시간치를 태웠다. **모델과 호출 수를 안 줄이면 게이트만으론 못 막는다.**

### 2. 배포 — git 없이 tar 패치
- 파일을 폰에서 만들어 `scp` → 이름이 잘린 채 도착(`server/s`, `server/exch`, `~/tr`, `~/auth-1.js`, `test/agents.test.mj`) → 손으로 `mv` → 재시작. 이력에 이런 복구가 7번 있다.
- 무엇이 언제 바뀌었는지 추적 불가. 되돌리려면 `backup-before-*.tar.gz` 를 통째로 풀어야 했다.

### 3. 설정 — 조용히 틀어져 있던 것들
- 시간대 UTC → 예약·일간요약 시각이 9시간 어긋남. 스왑 0 → 2GB 인스턴스에서 여유 없음.
- 미국주식(V·NVDA·AAPL·META·WMT·QQQ·MSFT)은 **바이낸스에서 거래 자체가 안 되는데** 분석 한도만 소모했다. 09-24에야 BTC·ETH로 고정.
- `marketHoursOnly` 필터가 **암호화폐까지 미국 장중으로 제한**해 이틀간 분석이 0건이었다. 09-26에야 24시간 체제로.
- 포트 8000이 전 인터넷에 열려 있었다(로그인 페이지가 막아주긴 했다).

### 4. 증거 기근 — 배울 데이터가 안 쌓이는 구조
- 11일간 판정 42건 중 **HOLD 36건(86%)**. 방향 판정 6건, 데모 체결 3건. 이 속도면 통계가 나오기까지 **1년**이 걸린다.
- 결과: "뭔가 돌긴 도는데 아무 일도 안 일어난다" → 계속 손대게 됨 → 1·2번이 악화.

## 버릴 것
- tar 패치 방식 전부. 배포는 `git pull` 만.
- 미국주식 유니버스(바이낸스 거래 불가). 코드는 남기되 `universe.js` 가 BTC·ETH로 잠근다.
- `opus` 자동분석. 수동 심층 분석에만 쓴다.
- 실패 시 재시도 — 한도 메시지면 재시도 금지(코드 수정).

## 이번엔 다르게 — 결정 사항

1. **서버 버전 코드를 새 기준으로 채택**하고 git 에 넣었다(이 저장소). 배포 = `git pull && npm test && systemctl restart`.
2. **자동분석은 `sonnet`**, 하루 상한 8회(`analysisBudget`), 실패 재시도 금지, 한도 게이트 문구 전부 인식.
3. 설치 스크립트가 **KST·스왑·.env·systemd** 를 고정한다. 손으로 만지는 설정은 `config.json` 하나.
4. **백테스터를 먼저 만든다.** 23.6만 봉 데이터로 감시 트리거 규칙(급변동+구조/역추세)을 Claude 호출 없이 몇 초 만에 검증한다. 영상에서 뽑은 규칙도 같은 틀에 태운다. 증거 기근을 여기서 끝낸다.
5. 실제 돈은 계속 0원. 데모 체결 30건 + 백테스트 근거가 갖춰지기 전엔 실계좌 URL 을 바꾸지 않는다.
